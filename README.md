# DESERT MERZOUGA

Site web professionnel dédié aux circuits touristiques, excursions et expériences dans le désert de Merzouga, Maroc.

## 🌵 Présentation

**DESERT MERZOUGA** propose des expériences touristiques dans le Sahara marocain :

* 🐪 Excursions à dos de dromadaire
* 🏜️ Circuits dans le désert
* ⛺ Bivouacs et camps de luxe
* 🌅 Couchers de soleil dans les dunes
* ⭐ Observation des étoiles
* 🚙 Circuits privés et personnalisés

## 🚀 Installation sur GitHub Pages

### 1. Télécharger le ZIP

Décompressez :

```text
DESERT_MERZOUGA.zip
```

Vous trouverez :

```text
index.html
README.md
```

### 2. Ouvrir votre dépôt GitHub

Connectez-vous à GitHub puis ouvrez le dépôt du site.

### 3. Ajouter les fichiers

Cliquez sur :

**Add file → Upload files**

Puis ajoutez :

```text
index.html
README.md
```

### 4. Enregistrer

Cliquez sur :

**Commit changes**

### 5. Activer GitHub Pages

Dans votre dépôt :

**Settings → Pages**

Dans **Build and deployment** :

* Source : **Deploy from a branch**
* Branch : **main**
* Folder : **/ (root)**

Puis cliquez sur **Save**.

Après quelques minutes, le site sera disponible avec votre adresse GitHub Pages.
