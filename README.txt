DESERT MERZOUGA
==============================

Luxury Desert Tours & Experiences
Merzouga - Sahara Marocain


PRESENTATION
------------

DESERT MERZOUGA est un site web dédié aux circuits touristiques,
excursions et expériences dans le désert de Merzouga au Maroc.

Le site présente des circuits privés, des excursions en dromadaire,
des bivouacs de luxe, des couchers de soleil, l'observation des
étoiles et des expériences personnalisées dans le Sahara marocain.

GITHUB PAGES
------------

Pour publier le site sur GitHub Pages :

1. Décompresser DESERT_MERZOUGA.zip.
2. Ouvrir le dépôt GitHub du projet.
3. Ajouter le fichier index.html.
4. Cliquer sur "Commit changes".
5. Aller dans Settings.
6. Aller dans Pages.
7. Sélectionner :
   Branch : main
   Folder : / (root)
8. Cliquer sur Save.

Après quelques minutes, le site sera disponible sur l'adresse
GitHub Pages du projet.
